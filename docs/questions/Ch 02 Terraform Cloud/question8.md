# Sentinel Policy Language

## Which language is used to write Sentinel policies in Terraform Cloud?

- [ ] HCL
- [ ] JSON
- [x] Sentinel Language
- [ ] Rego

### Answer Explanation

- **Sentinel Language**: Sentinel policies are written in the Sentinel Language. It is a purpose-built language for policy-as-code, designed to be approachable and easy to understand.

- **HCL**: Terraform configurations are written in HCL, but Sentinel policies are not.
- **JSON**: While Sentinel can consume JSON data, the policies themselves are written in Sentinel Language.
- **Rego**: Rego is the policy language used by Open Policy Agent (OPA), not Sentinel.

### Summary

Sentinel policies in Terraform Cloud are written in the **Sentinel Language**.
